# site-FRE2G

## Agent FRE2G

Le dossier [`agent/`](agent/) contient l'agent qui automatise le circuit d'un chantier FRE2G :
devis au modèle FRE2G (rédaction possible par Claude) → envoi au client avec signature électronique →
à la signature : fiche client, commande au fournisseur, facture d'acompte → acompte encaissé : travaux →
installation terminée : facture du solde et client classé « installé ».

Installation et mode d'emploi : [agent/README.md](agent/README.md).
